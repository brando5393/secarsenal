Tails ("The Amnesic Incognito Live System") is a live operating system
you boot from a USB stick, designed to leave no trace on the computer
you use it on and to route all network traffic through the Tor network.
It's used for anonymity research, privacy-sensitive work, and situations
where operators need to avoid leaving forensic artifacts on host
hardware.

Use it only for lawful purposes and only against systems/networks you
own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
