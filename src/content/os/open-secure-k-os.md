gettingStarted: |
  Open Secure-K OS boots from a USB key and stores user/system data
  AES-encrypted on that same key rather than the host's hard disk. It's
  a community continuation of the original commercial Secure-K OS
  (whose own site has since gone offline). It uses the Tor Browser for
  anonymous browsing and the Tox messenger for secure communication,
  and follows a "liveng" partitioning scheme that lets the read-only
  system partition be updated without touching the user's encrypted
  data.

Open Secure-K OS occupies the same privacy/anonymity niche as Tails and
Whonix already in this catalog — Tor-routed browsing, encrypted
persistent storage on removable media — as a smaller, community-run
alternative.

Use it only for lawful purposes and systems you're authorized to use —
see the [disclaimer](/disclaimer).
