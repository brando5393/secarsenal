Fedora Security Lab is an official Fedora spin built for security
auditing, digital forensics, and system rescue, oriented toward
teaching security-testing methodology as well as hands-on use.

Use it only against systems you own or are explicitly authorized to
test — see the [disclaimer](/disclaimer).
