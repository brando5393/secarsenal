Frieren provides an open-source alternative to the commercial WiFi
Pineapple: a web panel, integrated terminal, and package manager for
running wireless-auditing modules on generic router/SBC hardware
running OpenWrt, rather than a dedicated proprietary device.

Use it only against networks you own or are explicitly authorized to
test — see the [disclaimer](/disclaimer).
