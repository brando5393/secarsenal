This tool extracts interesting bits from network traffic. One use is to feed the “hamster” tool. Another use is to dump the output intoa text file, then use indexers and grep programs to analyze it.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
