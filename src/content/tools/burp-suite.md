Burp Suite is the standard toolkit for web application security testing:
an intercepting proxy plus tools for manually manipulating requests
(Repeater), automating payload testing (Intruder), and crawling/scanning
an application for vulnerabilities.

Only test web applications you own or are explicitly authorized to
assess — see the [disclaimer](/disclaimer).
