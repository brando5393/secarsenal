This package contains modified versions of Curl, Iceweasel, FreeTDS, Samba 4, WinEXE and WMI. They are installed as executables starting with the “pth-” string.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
