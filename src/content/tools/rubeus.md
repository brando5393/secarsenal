Rubeus is a C# toolset for raw Kerberos interaction and abuses. It is heavily adapted from Benjamin Delpy’s Kekeo project and Vincent LE TOUX’s MakeMeEnterpriseAdmin project.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
