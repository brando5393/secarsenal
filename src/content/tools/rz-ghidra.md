This is an integration of the Ghidra decompiler and Sleigh Disassembler for rizin. It is solely based on the decompiler part of Ghidra, which is written entirely in C++, so Ghidra itself is not required at all and the plugin can be built self-contained.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
