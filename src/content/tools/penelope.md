Penelope is a modern shell handler designed for penetration testers and CTF players. It provides a highly capable alternative to basic netcat listeners, streamlining reverse and bind shell management during post-exploitation.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
