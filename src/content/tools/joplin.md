This package contains a free, open source note taking and to-do application, which can handle a large number of notes organised into notebooks. The notes are searchable, can be copied, tagged and modified either from the applications directly or from your own text editor. The notes are in Markdown format.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
