This package contains a collection of WPA/WPA2/WPS default algorithms/password generators/pingens written in C. This is useful for testing/auditing wireless networks and contains bleeding edge algorithms.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
