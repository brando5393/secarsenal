This package contains a plugin for Simon Willison’s LLM tool that provides Nmap network scanning capabilities through function calling. This plugin enables LLMs to perform network discovery and security scanning tasks using the powerful Nmap tool.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
