This package contains a proof of concept Command and Control framework, written in Golang, that uses DNS-over-HTTPS as a transport medium. Currently supported providers include Google, Cloudflare but also contains the ability to use traditional DNS.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
