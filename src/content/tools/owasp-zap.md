OWASP ZAP (Zed Attack Proxy) is a free, open-source web application
security scanner maintained under the OWASP umbrella. It combines an
intercepting proxy with automated crawling/scanning, making it a common
free alternative or complement to Burp Suite for web app assessments.

Only test web applications you own or are explicitly authorized to
assess — see the [disclaimer](/disclaimer).
