This is the repository of the RF Analyzer app for Android. It can be used to view a FFT plot and a waterfall plot of the frequency spectrum received by a HackRF. The new version can also demodulate audio from AM and FM signals!

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
