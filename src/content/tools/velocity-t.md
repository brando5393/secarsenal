Self-hosted, open-source (AGPL) flight and ship tracker that fuses public ADS-B and AIS feeds without API keys and records every position it sees, so past traffic can be replayed from your own disk.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
