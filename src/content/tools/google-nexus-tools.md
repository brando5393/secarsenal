Nexus Tools is an installer for the Android debug/development command-line tools ADB (Android Device Bridge) and Fastboot for Mac OS X, Linux, and Google Chrome/Chromium OS.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
