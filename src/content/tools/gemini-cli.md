This package contains an open-source AI agent that brings the power of Gemini directly into your terminal. It provides lightweight access to Gemini, giving you the most direct path from your prompt to the model.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
