This package contains a Python tool for preparing existing wordlists. It returns a selection of words that matches the passed conditions in an existing list. As an example you have a GB big wordlist and you only want passwords with a length of at least 8 characters. This optimizes word lists and saves unnecessary requests.

Only use this tool against systems you own or are explicitly authorized to test — see the [disclaimer](/disclaimer).
